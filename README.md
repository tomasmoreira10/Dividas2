Aplicação web simples para controlar dívidas e divisões de grupo.

Ficheiros principais
index.html: aplicação completa
manifest.json: configuração PWA
sw.js: service worker para funcionamento offline
icon-c.svg: ícone principal
icons/icon-192.svg: ícone 192x192
icons/icon-512.svg: ícone 512x512
Como publicar no GitHub Pages
Criar um repositório no GitHub.
Fazer upload destes ficheiros.
Ir a Settings → Pages.
Escolher a branch principal e guardar.
A aplicação ficará disponível num link público.
